# WAKE 無料公開版

競艇AI予想「WAKE」の無料公開版（ログイン不要）。

## これは何か

有料版（[newhunaken456](https://github.com/Hunaken-akademia/newhunaken456)）と同じVercelプロジェクトの公開APIを呼び出すだけの、単一HTML+JSの軽量フロントです。予想ロジック本体（採点式・重み・場別実データ補正）はここには一切含まれません。

- `/api/yoso`（newhunaken456側、既存・ログイン不要）で出走表・展示を取得
- `/api/stats`（同、既存・ログイン不要）で選手の過去成績（race_results）を取得し、
  枠別成績（win1/ren2/ren3、直近6ヶ月・進入コース別）を組み立てて`/api/predict`へ渡す
- `/api/predict`（同、Authorizationヘッダを付けずに呼ぶ）でAI予想を取得
  - サーバー側（`getPaidEntitlement`）がAuthorizationヘッダの有無・有効性を見て、
    ログイン無しの呼び出しには自動的に縮小レスポンス（総合1位・2位の艇・荒れ度バッジ・
    見送りAI判定のみ）を返す。買い目・3位以下・スコア・根拠の数値はサーバー側で
    最初から除外されており、このリポジトリのコードにも一切含まれない。

## 表示する項目（無料）

- 出走表（艇番・選手名・級別）
- AIの総合上位2艇とその印（枠別成績・展示・モーター・STの4項目判定込み）・予想3連対率
- 荒れ度バッジ（本命／やや本命／混戦／大混戦）
- 見送りAI判定（勝負／慎重／見送り推奨、数値根拠なし）

## 表示しない項目（有料版限定）

- 穴目（3〜6位の評価）
- 買い目（3連単・フォーメーション）
- 平均ST・決まり手・逃げシミュ・攻められ耐性などの根拠内訳
- 1番人気との一致判定、見送りAIの数値根拠

## デプロイ

Vercelにgit連携するだけ（ビルド不要、`vercel.json`で静的配信に固定）。
